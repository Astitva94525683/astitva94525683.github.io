How I work

A forward deployed engineer sits with the customer, builds on the customer's own data, and stays until the thing is used. I run the same four steps on every deployment. Each one below is backed by what I did on Akris.

  2. 1

    Discover

    Sit with the operators, map how the work happens today, and pick the problem that has a number attached.

    On AkrisMapped the plant's lookup path (Oracle, saved query, Excel, about 5 minutes and desk-only), wrote a 14-page PRD, and framed the pitch to the COO around scrap.

  3. 2

    Build

    Put a working agent on the customer's real data early, then iterate with the people who use it every shift.

    On AkrisA four-stage text-to-SQL agent on live Oracle data, with intent routing, BM25 retrieval with acronym expansion, and a value resolver that snaps literals to real values.

  4. 3

    Harden

    Make it safe to leave running: guardrails, fallbacks, evaluation and a human who approves what the system learns.

    On AkrisEvery generated query passes a read-only guard and a compile check. Failed questions fall back to a second LLM. Engineer feedback becomes rules that are replayed on verified answers and released only after approval.

  5. 4

    Prove

    Measure the result in the customer's own terms and take it to the people who fund the next phase.

    On AkrisTimed demos (5 min to 50 s; about 30× on per-rod lookups), ₹6.75 lakh a year in projected staff time, a presentation to the COO, and the STL AI Award.

In productionSterlite Technologies, optical fibre plant

Akris

A chat agent that turns plain-English questions about live plant data into checked SQL, tables and charts, so engineers stop waiting on saved queries and spreadsheets.

Problem
A routine lookup meant Oracle, a saved query and Excel: about 5 minutes, desk-only. Leadership requests took hours, and new joiners collected conflicting answers person to person.
What I shipped
  • A four-stage workflow (understand, plan, verify, answer) with a read-only guard and a compile check on 100% of generated SQL.
  • A fallback to a second LLM for questions the first one fails.
  • Human-in-the-loop learning: background analyst agents turn Right/Wrong feedback into rules, replay them on verified answers (25% to 38% correct) and wait for approval.
  • Deployed with plant IT so the agent reaches the production database securely. I am the only engineer on it: I wrote the code and run the deployment.
Result
About 30 plant staff use it. Timed demos cut a monthly scrap-rate query from 5 minutes to 50 seconds and per-rod lookups about 30×. Presented to the COO, Optical Networking Business; won ₹1,00,000 at the STL AI Awards.
